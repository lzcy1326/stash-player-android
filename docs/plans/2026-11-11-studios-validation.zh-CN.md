# 厂商页面开发与验收记录

## 参考与设计

2026-11-11 使用用户已登录的 Chrome 查看 Stash 厂商列表、排序选项、筛选编辑器和 S1 详情。通过只读 GraphQL introspection 核对实际字段，不保存服务地址、凭据或个人资料。

样式严格延续手机版演员页：系统字体和 Material 字阶，标题、搜索、组合排序和筛选对齐；搜索框与控制条圆角 14dp，列表横向留白 16dp，卡片间距 12dp。采用当前主题语义颜色，默认深色参考值为背景 #070A12、表面 #0B1020、变体 #1A2030、主色 #7C3AED、正文 #F8FAFC，浅色与自定义主题均从 MaterialTheme 继承。

厂商以 Logo 为识别重点：两列自适应卡片，Logo 区域比例 1.6:1，使用 Fit 完整展示；详情使用 96dp 紧凑 Logo、收藏、评分、可展开别名和父子关系；长资料默认折叠。相比演员的竖幅照片，Logo 卡片更扁，以提高浏览密度。影片卡片、搜索排序、标签及日期/时长/评分/格式筛选、收藏/稍后看/队列动作沿用已实现组件。

## 实现范围

- 厂商导航入口替换占位页，新增列表及详情路由。
- 搜索名称/别名、姓名/评分/影片数量/最新影片/更新/创建/子厂商数量/图片数量/图集数量/固定种子随机排序、正倒序、分页、刷新、错误重试和空状态。
- 厂商筛选：服务端收藏、评分范围、影片数量范围、标签、父厂商、已整理状态；草稿应用/取消/清除与已应用条件摘要。
- Logo 预览、别名、介绍、网址、标签、Stash ID、父子厂商跳转；服务端收藏和评分/清空评分在列表与详情同步。单字段写入、并发保护、失败后读取权威值。
- 详情默认只看直属影片，显式开关包含子厂商（depth=-1）；数量/时长/体积随范围更新。用户影片条件与固定厂商范围 AND 组合，播放列表续页保留服务器、厂商、子厂商范围及筛选。
- 厂商内容编辑/删除、自动标记，以及厂商的图集/图片/演员/组独立内容页不在本次移动端浏览开发范围。

## 验收

- 前次会话已通过已登录的 Chrome 核对网页布局。真实接口使用 `StudioFilterType.favorite`，厂商影片范围以 `depth=0` 查询直属影片，以 `depth=-1` 包含子厂商。
- 37 项单元测试通过，`lintDebug` 完成，报告有 0 个错误和 162 条警告。
- 使用最终构建在模拟器上通过 16 项厂商测试及 4 项演员页回归测试。演员页筛选测试先通过索引滚动并检查目标项可见，再验证筛选后回到首项。
- 模拟器连接已配置的真实 Stash 服务，验证了厂商列表、搜索后进入详情、Logo 加载、影片卡片、返回后保留搜索、层级范围和排序分页。真实服务验收仅执行读取，收藏与评分写入由模拟请求覆盖。
- Debug APK 位于 `build/outputs/preview/stash-player-studios-20261111-debug.apk`，已通过 Android SDK 签名校验。
