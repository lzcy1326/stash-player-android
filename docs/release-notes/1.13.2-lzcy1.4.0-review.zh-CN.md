# 1.13.2-lzcy1.4.0 发布日志（审查稿）

## 本次更新

- 新增 Android TV 体验版：支持遥控器操作、影片浏览和搜索、播放、切换播放源及续播。
- 电视显示二维码后，可使用手机端扫码并确认，将手机已保存的服务器配置发送到电视；扫码后电视显示等待确认状态。
- 手机首页新增扫一扫入口并改用刷新图标；扫码页面默认竖屏，优化屏幕边缘的文字显示。

## 使用说明

- 电视版是独立安装的 MVP 体验版，使用调试签名且允许调试，功能和兼容性仍在验证中。
- 扫码配对时，手机和电视需要连接同一局域网。
- 已在 TCL Q9K 电视完成服务器连接和视频播放的基本验证；更多电视型号及完整功能仍需进一步验证。
- 采用常规版本码。已安装较高版本码测试包的设备不能直接覆盖安装本版；如需重装，应先备份本地配置。

正式发布说明以审查后的 [CHANGELOG.md](../../CHANGELOG.md) 对应版本内容为准。
